# Ψ PsyPing

**Омниканальный сервис случайных психологических напоминаний с защитой от баннерной слепоты (анти-привыкание).**

Реализован по архитектуре обсуждения [share.gemini.google/NosjywCmdU35](https://share.gemini.google/NosjywCmdU35).

---

## 🎯 Проблема и Решение

1. **Проблема:** Однотипные напоминания в одном и том же канале (например, пуши одного приложения в 12:00) быстро вызывают *баннерную слепоту*. Мозг привыкает и смахивает их на автопилоте не глядя.
2. **Решение PsyPing:**
   - **Непредсказуемость времени (Poisson Jitter):** случайные интервалы с учетом «тихих часов».
   - **Смена сенсорного канала (Anti-Fatigue Roulette):** то всплывающее окно на мониторе ПК, то текстовый пинг в Telegram, то реалистичное голосовое сообщение в наушники, то мобильный push через ntfy.sh, то звуковой гонг в браузере.
   - **Мутация текста (AI / Smart Fallback):** LLM (Gemini Flash / GPT-4o-mini) или умный офлайн-рандомизатор каждый раз перефразирует вопрос, чтобы глаз не встречал знакомую формулировку.
   - **Фиксация факта (Кнопка «Сделал ✓»):** нажатие кнопки в Telegram, Windows Toast или дашборде подтверждает выполнение практики и повышает доверие к каналу. Если канал игнорируют — его вес в рулетке временно снижается.
   - **Мультипользовательская архитектура (SaaS / Cloud-Ready):** каждый участник получает изолированный профиль по персональной ссылке (`/?u=...`) или автоматически при отправке команды `/start` в Telegram-бот.

## ☁️ Развёртывание в облако (Доступно всем 24/7)

Сервис полностью упакован в `Dockerfile` и поддерживает моментальный деплой на бесплатные хостинги из репозитория GitHub:

### Вариант 1: Render.com (Бесплатно, 1 клик)
1. Зайди на [dashboard.render.com](https://dashboard.render.com).
2. Нажми **New +** -> **Web Service** -> выбери репозиторий `artemonyocmo/psyping`.
3. Render автоматически определит `Dockerfile` и настройки из `render.yaml`.
4. Нажми **Deploy**. Сервис получит постоянный публичный адрес: `https://psyping-xxxx.onrender.com`.

### Вариант 2: Railway.app
1. Зайди на [railway.app](https://railway.app).
2. Нажми **New Project** -> **Deploy from GitHub repo** -> выбери `artemonyocmo/psyping`.
3. Добавь переменную окружения `PORT=8000`.

## 👥 Как этим пользоваться другим людям

1. **Через Telegram-бота (Самый простой путь для друзей):**
   - Владелец сервиса указывает `TELEGRAM_BOT_TOKEN` в настройках дашборда.
   - Любой человек открывает бота и нажимает `/start`.
   - Бот мгновенно регистрирует человека, присылает ссылку на его личный веб-дашборд и начинает присылать случайные напоминания (текстом и голосом) прямо в Telegram.
2. **Через персональную ссылку:**
   - Человек переходит по ссылке `https://<твой-домен>/?u=ivan`, нажимает «Включить пуши браузера» и настраивает тихие часы под себя.
3. **Через ntfy.sh (Push на Android / iOS без бота):**
   - Пользователь вводит любой уникальный топик (например, `psyping_ivan`) и подписывается на него в бесплатном мобильном приложении ntfy.

## 📡 Каналы доставки (Omnichannel Matrix)

| Канал | Способ воздействия | Особенности |
|---|---|---|
| **Telegram (Текст)** | Сообщение от бота в личку | Inline-кнопки `[Сделал ✓]` и `[Отложить]` |
| **Telegram (Голос)** | Аудиозапись кружком/voice в Telegram | Синтез естественной русской речи (Edge TTS / OpenAI) |
| **ntfy.sh** | Мгновенный Push на смартфон и ПК | Бесплатно, без регистрации: топик в приложении ntfy (iOS / Android) |
| **Web Dashboard** | Звук тибетской чаши (Web Audio API) + Web Push | Всплывает прямо на открытой странице |
| **Custom Webhook** | HTTP POST JSON | Для умного дома (Home Assistant, колонка Алиса, MacroDroid) |
| **Windows Toast** | Нативное системное окно в углу монитора | Доступно при локальном запуске на Windows |
